# 截图文档复刻为 PDF

把用户提供的文档类截图（简历、证书、海报、表格、单据等）高保真复刻成无水印 PDF，并保留可编辑的 HTML 源文件。

## 何时使用

用户发来一张或多张文档截图，并要求：复刻、照版式重做、转成 PDF、去水印重排、把图片里的文档变成可打印文件。

## 铁律

1. 复刻范围只针对文档本体。截图带入的浏览器边框、标签栏、桌面背景、聊天窗口、鼠标指针等无关元素一律排除，不进入复刻稿。
2. 只复刻有证据的内容。截图缺角、缺行、文字模糊到无法可靠辨认时，列出缺失清单请用户补充；禁止编造或凭常识补齐。
3. 文字逐字照抄：不润色、不纠错、不改写、不翻译。原文的错别字也保留，可在交付说明里另行提示。
4. 字体只能近似替代：截图来源平台的付费商用字体通常无法获得，一律用最接近的系统字体，并在交付时向用户说明这一点。
5. 页数必须与原版一致：原版单页就输出单页，绝不溢出到第二页；多页文档按原版页数逐页复刻。
6. 默认 A4 竖版。原版明显不是 A4（如宽幅海报）时按原版宽高比设定纸张，并在交付说明里注明。
7. 输出格式默认 PDF。用户指定其他格式时按「输出格式」一节路由；未指定的格式不主动产出。
8. 分析确认后才生成：前置分析输出并经用户确认前，不开始写 HTML、不导出任何文件。
9. 颜色必须采样得来（完整档）：凡有彩色标签、图标、进度条、装饰图形的文档，填色值必须来自 `scripts/sample_colors.py` 的报告，禁止肉眼估色；图标必须先列语义清单再画（规范见 `references/layout-measurement.md` 第七、八章）。

## 输出格式

| 格式 | 路由 | 说明 |
|---|---|---|
| PDF（默认） | `scripts/export_pdf.py` 无头打印 | 自动校验页数，主交付物 |
| PNG | 宿主有 PyMuPDF：`pymupdf` 渲染 PDF 每页为 PNG（建议 150dpi 以上）；无 PyMuPDF：单页文档可用 Chrome `--screenshot --window-size=794,1123` 兜底 | 多页文档在兜底路径下标注「部分验证：仅首页」 |
| Word | 降级交付：HTML 源文件 + 「用 Word 打开 HTML → 另存为 .docx」三步手动指引 | 未实测自动转换，交付时明确标注 |

## 流程

1. **前置分析并等用户确认**（硬闸口）：收到截图后先输出分析，固定顺序：
   - **① 总页数**：明确写出「这份文档共 N 页」，放在分析最前面；
   - **② 差异问题清单**：逐条列出各页字体不一致、内容重复、缺角/缺行、水印覆盖、其他异常；没有问题的维度也要写「无」；
   - **③ 整体内容概述**：这份文档是什么、有哪些板块、大致内容，三五句话说清。

   分析输出后**停下等用户确认**；用户提出修正就改完分析再确认，确认无误后才进入下一步。
2. **多截图去重合并**：多张截图时识别重复与重叠——同一页被重复截的只保留最清晰一张；跨页内容重叠的按衔接处合并去重；各页按页序排列。判断不了是否重复/衔接时问用户，不猜。方法见 `references/layout-measurement.md` 第一章。
3. **判断截图边界**：确定每页哪块矩形区域是文档本体（通常是承载内容的白色/纯色内容区）。截图含无关元素时直接忽略。无法判断边界时问用户。
4. **提取文字**：通读文档本体区域，逐字记录全部文字，并标注结构（姓名/标题、板块标题、条目名称、时间、列表项、加粗与标签）。
5. **测量版式**：先按 `references/layout-measurement.md` 第零章做复杂度分档（简单档/完整档）。简单档直接量字号、间距、对齐、页边距、页数；**完整档在量取前先跑 `scripts/sample_colors.py <截图>`**，按报告填配色，并按图标复刻规范列图标清单。
6. **写 HTML 复刻稿**：按测量结果写单文件 HTML（内联 CSS），A4 版式，多页文档用分页符按原版分页，间距从紧凑起步。
7. **导出文件**：先运行 `scripts/check_environment.py` 确认浏览器可用；ready 后按用户选定的输出格式导出（默认 PDF：`scripts/export_pdf.py <HTML绝对路径> <PDF绝对路径>`）。缺失浏览器时按 `references/setup-guide.md` 引导安装或降级。
8. **自检**（缺一不可）：
   - 页数等于原版；不等则按边界与降级里的压缩顺序回调；
   - 渲染预览图逐区对照截图：页眉区、每个板块、每个条目、页脚；
   - 文字与截图逐字比对，含标点、数字、大小写、加粗位置。
9. **交付**：按用户选定格式的成品 + HTML 源文件，附交付说明（输出模板见下）。

## 边界与降级

| 情况 | 处理 |
|---|---|
| 截图模糊、关键文字无法可靠辨认 | 停止复刻，列出无法辨认处请用户补图（停止条件，不用猜） |
| 截图缺角、内容被裁掉 | 指出缺了什么，请用户补全后再做；用户确认按现有内容做时才继续，并在交付说明标注缺失区域 |
| 无 Chromium 浏览器（Chrome/Edge） | 输出 needs_setup 安装指引；用户可选手动降级：交付 HTML + “浏览器打开 → 打印 → 另存为 PDF” 步骤，标注 PDF 未生成、页数未验证 |
| PDF 页数多于原版 | 只压缩间距，按顺序每次改一档重导：① 板块间距 ② 列表项间距 ③ 页边距 ④ 正文字号（降幅最小档）。不动文字内容 |
| 多张截图 | 重复截图去重保留最清晰一张；跨页重叠按衔接处合并；页序混乱时向用户确认顺序 |
| 用户指定 PNG 而宿主无 PyMuPDF | 单页文档用 Chrome 截图兜底；多页文档如实标注「部分验证：仅首页」，建议改用 PDF 或安装 PyMuPDF 后重试 |
| 用户指定 Word | 交付 HTML 源文件 + Word 打开另存 .docx 的手动指引，标注未实测 |
| 导出失败 | 保留 HTML 复刻稿，如实报告失败原因和已验证/未验证范围 |

## 交付说明模板

```text
复刻完成：<文件名>（格式：<PDF/PNG/Word指引>，<页数> 页，与原版一致/不一致说明）
- 内容：逐字核对结果（一致 / 列出差异）
- 版式：结构、间距、对齐、配色对照结果
- 颜色（完整档）：颜色对照表（元素 / 原版采样值 / 复刻值，逐项列出）
- 字体：近似替代说明（原版字体 → 实际使用字体）
- 无法复刻的元素：图标重绘/装饰替代等差异清单
- 附带：HTML 源文件路径（可自行修改后用浏览器打印另存为 PDF）
```

## 质量自查清单

- [ ] 前置分析已按「总页数 → 差异清单 → 内容概述」输出并经用户确认
- [ ] 多张截图已完成去重合并，页序正确
- [ ] 截图边界判断完成，无关元素全部排除
- [ ] 全部文字逐字提取并与截图比对通过
- [ ] 复杂度分档已完成；完整档已跑 sample_colors.py 且填色值全部来自采样报告
- [ ] 完整档图标已按语义清单枚举、风格与原版图一致
- [ ] 页数与原版一致
- [ ] 页眉、板块、条目、页脚逐区视觉对照通过
- [ ] 字体近似替代已向用户说明
- [ ] 输出格式符合用户选择（默认 PDF）
- [ ] 成品与 HTML 源文件一并交付
