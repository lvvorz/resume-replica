# 版式测量与边界判断

## 零、复杂度分档（决定测量流程轻重）

拿到截图先做分档判断：

| 档位 | 判定标准 | 流程 |
|---|---|---|
| **简单档** | 无彩色标签、无图标、无进度条/装饰图形，配色只有黑/灰/白 | 跳过颜色采样，用骨架模板的默认色值，走快速流程 |
| **完整档** | 命中任一：彩色标签（如 211 徽章）、联系行/板块图标、进度条、装饰色块/图形、非灰配色 | **必须先跑 `scripts/sample_colors.py`**，按报告填色；按「图标复刻规范」处理图标；交付附颜色对照表 |

不确定属于哪档时按完整档处理。分档判断结果写进前置分析的②。

## 〇、多截图去重合并

收到多张截图时按以下顺序处理：

1. **识别重复截图**：比对各张的版式（字号、板块结构、配色、页眉页脚）与文字内容。同一页被重复截的（内容完全或几乎一致），只保留最清晰的一张，其余丢弃；清晰度接近时保留信息最全的一张（如一张缺角、一张完整，保留完整的）。
2. **识别跨页重叠**：相邻页之间常有重复区域——页眉、页脚、续接的条目（上一页末尾和下一页开头是同一行/同一条）。比对相邻两张的尾部与头部内容，把重叠部分在合并稿里只保留一次。
3. **确定页序**：按内容衔接关系排序（如简历的"工作经历"板块从第 1 页续到第 2 页）。衔接关系对不上、或出现内容明显不属于同一份文档的截图时，停下来问用户，不猜。
4. **得出总页数**：去重合并后的页数就是文档总页数，写进前置分析的①。

判断信号：页眉/页脚文字相同、时间线或条目编号连续、板块标题在两张图里只出现一次。

## 一、判断截图边界

文档本体的判定信号（按优先级）：

1. **承载内容的矩形区**：文档内容集中在一块背景纯净（多为白色）的矩形内，矩形外是浏览器边框、标签栏、工具栏、桌面壁纸等。只复刻矩形内的部分。
2. **水印处理**：截图平台加在文档页面上的半透明水印（斜向文字、Logo）属于平台元素，不属于文档本体，复刻时直接去掉，不画进复刻稿。
3. **多截图拼接**：几张截图的版式（字号、板块结构、配色）一致且内容前后衔接，视为同一文档的连续部分；否则按独立文档分别复刻。
4. **判断不了就问**：截图被其他窗口遮挡、边界不清晰时，向用户确认文档范围，不自行猜测。

## 二、像素测量法

以文档本体区域的宽度为基准换算比例：

- A4 纸在 CSS 中宽 210mm ≈ 794px（96dpi）。设截图中文档本体宽 W 像素，则 **比例尺 = 794 ÷ W**。
- 截图中测得某段间距为 p 像素 → CSS 像素值 ≈ p × 比例尺。
- 字号估算：中文方块字高度 ≈ 字号。测一行文字的行高像素 h → 字号 ≈ h × 比例尺，就近取整到 0.5px。
- 配色（完整档强制）：**禁止肉眼估色**，先跑 `scripts/sample_colors.py <截图>`，按输出的分类色频和通栏长条报告填色：
  - 「深蓝装饰/技能条」「蓝色标签」「暖色标签」三类各取 n 值最大的色作为该类代表色；
  - 「通栏长条」报告里的行就是分隔线/色带，**它的颜色就是分隔线颜色**——不要想当然用深色；
  - 报告没覆盖的特殊色（如某种品牌色文字），用图像查看器取色器补采，同样记录十六进制。
  - 脚本缺 Pillow 时的手动降级：用任意图像查看器的取色器，至少采样 3 类代表色（分隔线、标签底、正文），并注明「手动采样」。
- 页数：根据截图总高与单页文档区域高的比例，结合内容截断位置判断原版页数。

## 三、字体替代表

| 截图中的字体特征 | 替代方案（font-family 按顺序） |
|---|---|
| 中文黑体（最常见） | "Microsoft YaHei", "PingFang SC", sans-serif |
| 中文宋体/衬线 | SimSun, "Songti SC", serif |
| 中文楷体 | KaiTi, "Kaiti SC", cursive |
| 英文无衬线 | Arial, Helvetica, sans-serif |
| 英文衬线 | Georgia, "Times New Roman", serif |
| 等宽 | Consolas, "Courier New", monospace |

英文/数字单独成行时，font-family 要把西文字体放中文字体前面，避免数字字形不一致。

## 四、HTML 骨架模板

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<style>
  @page { size: A4; margin: 0; }
  * { margin: 0; padding: 0; box-sizing: border-box; }
  html, body { width: 210mm; min-height: 297mm; background: #fff; }
  body { font-family: "Microsoft YaHei", sans-serif; color: #111;
         font-size: 12.5px; line-height: 1.75; padding: 26px 55px 30px 55px; }
</style>
</head>
<body>
  <!-- 文档内容 -->
</body>
</html>
```

## 五、间距紧凑起步（防溢出）

单页文档极易因间距偏大溢出成两页。写初稿时就按紧凑值起步：

- 页边距：上下 26px、左右 55px 起
- 板块间距（section 之间）：24px 起
- 板块标题下分隔线与内容：12px 起
- 列表项之间：5px 起
- 条目之间：10px 起

导出后若页数仍多于原版，按 SKILL.md「边界与降级」的压缩顺序逐档回调，每次只改一档、重新导出验证。

## 六、常见版式元素的复刻要点

- **居中页眉**：姓名/标题居中加粗，联系信息多行居中，行距 1.9 左右。
- **通栏分隔线**：板块标题下方 `border-bottom` 贯通内容区全宽，1.5px 深色。
- **左右分栏条目**：条目名左对齐加粗、时间右对齐，用 flex + `justify-content: space-between`。
- **小标签**：如「211」类色块标签，行高 1、小字号、圆角 3px、白字底色。
- **项目符号**：用 `::before` 画圆点，缩进对齐。

## 七、图标复刻规范（完整档强制）

复刻带图标的文档时，**先枚举图标清单再动手画**，禁止边画边猜：

1. **列清单**：逐个识别截图里每个图标的语义，写成对照表再复刻。联系行常见图标语义：电话、邮箱、定位、年龄（蛋糕）、性别（♂/♀）、职位（闪电/齿轮）、在职状态（圆圈）、城市（建筑）、薪资（钱袋）。截图里出现什么就列什么，数量以截图为准。
2. **风格跟随原版**：原版是细线框图标就必须用线性 SVG（`fill="none"` + `stroke`，统一 `stroke-width`，viewBox 用 24×24 或按原版比例）；原版是实心图标才用 `fill`。严禁线性/实心混搭。
3. **颜色用采样值**：图标颜色从 `sample_colors.py` 的报告里取（图标常落入「蓝色标签」或「深色文字」类别），禁止随手用默认深色。
4. **禁止自创形状**：不确定的图标形体，在自检环节把渲染预览放大对照；仍不确定就如实标注「图标为近似形体」，不编造。
5. **装饰图形单独记录**：弧形色块、星形、角标等装饰元素，位置用**页面百分比坐标**记录（如「四角星：右缘 x=100%、纵向 55% 处」），形状按原版的曲率/角数描述，不复用无关模板里的装饰。
6. **项目符号也是图标**：圆点的大小（直径≈正文字号的 25%~35%）、颜色都要按截图量，不许用默认大号圆点。

## 八、颜色复刻反面示例（真实失败样本，2026-10-24）

某带装饰的简历复刻交付后用户反馈「颜色深浅不准、图标形状不一致」，像素采样定位到三类典型错误：

| 错误 | 原版采样值 | 复刻值 | 教训 |
|---|---|---|---|
| 分隔线画成藏青粗线 | `#e0e0e0` 浅灰 | `#082868` 藏青 | 以为"标题下的线就该是深色"——**线的颜色必须采样**，`sample_colors.py` 的「通栏长条」报告就是干这个的 |
| 「211」标签画成亮蓝 | `#5a6e82` 灰蓝（低饱和） | `#3278d2` 高饱和亮蓝 | 凭印象选"常见的蓝色"——**饱和度必须由采样值决定** |
| 联系行图标换了一套 | 灰色细线框（电话听筒/信封/定位针/蛋糕…） | 深色实心感、电话变成圆圈内符号 | 没枚举图标清单、没确认风格类别——**先列清单、定风格、再画** |

执行完整档流程时，把本表当警示清单逐项自查。
